# 💻 Projeto JavaScript

Projeto desenvolvido durante meus estudos de **JavaScript**, reunindo exercícios e aplicações práticas para consolidar os fundamentos da linguagem e evoluir na área de desenvolvimento web.

## 🚀 Objetivo

O objetivo deste projeto é praticar JavaScript através de pequenos projetos e exercícios, desenvolvendo lógica de programação e aprendendo a criar aplicações interativas para a Web.

## 🧠 Conceitos estudados

Durante o desenvolvimento foram praticados conceitos como:

* JavaScript
* Variáveis e constantes
* Tipos de dados
* Operadores
* Condicionais
* Estruturas de repetição
* Funções
* Arrays
* Objetos
* Manipulação do DOM
* Eventos
* Formulários
* Manipulação de elementos HTML
* JavaScript assíncrono
* Organização de código

## ▶️ Como executar

Clone o repositório:

```bash
git clone SEU_REPOSITORIO
```

Entre no diretório:

```bash
cd Projeto-JavaScript
```

Depois, abra o arquivo:

```text
index.html
```

no navegador.

Para uma melhor experiência durante o desenvolvimento, também é possível utilizar o **Live Server** no VS Code.

## 🎯 O que este projeto representa

Este projeto representa uma etapa da minha evolução como desenvolvedor, colocando em prática os conhecimentos adquiridos durante meus estudos de JavaScript.

A ideia é transformar conceitos teóricos em aplicações funcionais e, gradualmente, aumentar a complexidade dos projetos.
